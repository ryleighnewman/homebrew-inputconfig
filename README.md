# homebrew-inputconfig

A [Homebrew](https://brew.sh) tap for [InputConfig](https://inputconfig.com), a free,
open-source controller mapper for macOS.

## Install

```sh
brew install --cask ryleighnewman/inputconfig/inputconfig
```

## Notes

This is the same app as the Mac App Store version, signed with Developer ID and
notarized by Apple. Tips are only available in the Mac App Store version.
