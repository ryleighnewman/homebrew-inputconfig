# Security Policy

This tap holds the Homebrew cask for [InputConfig](https://github.com/ryleighnewman/InputConfig). The cask
installs the Developer ID signed and notarized build attached to this repository's latest
release, and checks it against the cask's SHA-256 before installing.

## Supported versions

Only the version in the current cask is supported. Update with `brew upgrade --cask inputconfig`.

## Reporting a vulnerability

Please report security issues privately, not in a public issue.

- For a problem in InputConfig itself, follow the [InputConfig security policy](https://github.com/ryleighnewman/InputConfig/security/policy).
- For a problem with this tap, such as a cask that points to the wrong file, a checksum that does not match, or a download that is not signed and notarized, open the [Security tab](https://github.com/ryleighnewman/homebrew-inputconfig/security) of this repository and choose **Report a vulnerability**.

If you cannot use GitHub, reach out through [ryleighnewman.com](https://ryleighnewman.com).

You can expect a first reply within 7 days.
